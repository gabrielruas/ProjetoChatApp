## Pré-requisito

Para executar este projeto, é necessário instalar o [Node.js](https://nodejs.org/) na versão **LTS**. A instalação inclui o **npm**, utilizado para gerenciar as dependências e executar a aplicação.

## Como executar o projeto

### 1. Instalar as dependências

No terminal, dentro da pasta do projeto, execute:

```bash
npm install
```

### 2. Iniciar a aplicação

```bash
npm start
```

### 3. Acessar no navegador

Após iniciar a aplicação, acesse:

[http://localhost:3000](http://localhost:3000)
